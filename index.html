The Mainframe is, well… my site. Like everyone else, I have a small little site.

It was going to be a place for me to upload my guides and reviews for people who are mainly interested in vintage technology, but that fell through as my motivation to do such things is lacking. Don’t expect this place to be updated often.

At the top are some links which can guide you around the site. This site was originally going to have a template made from scratch, but I decided that doing so would take a lot of effort and time. Instead, I grabbed an already existing template. The site might end up much neater in the future but for now, take what I have to offer.

While it works okay on mobile devices, PC is preferred.

Latest update: March 1st, 2026 Update: Doing it all, in new ways.

Webmaster, the updates for your site aren't showing!

First, you should refresh the page with Ctrl + R if you are on Windows or Command + R if you are an Apple user. F5 usually works too.

If the first thing doesn't work for you, you should clear your browser's cache. GitHub uses CDN caching for pages so there is a small delay for changes to be reflected on the actual page. If you don't know how to clear your browser's cache, check this site out (or you can look it up on a search engine if your browser isn't there and uses a different method).

As for mobile users, I guess refresh the page or close it and open it up again.
